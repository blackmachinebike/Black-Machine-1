# Fotos de producto

Coloca la foto de cada producto con el mismo `id` del catálogo + `.jpg`:

- `p001.jpg`, `p010.jpg`, `p090.jpg`, ...

La tarjeta la toma automáticamente; si no existe, muestra el ícono de la categoría.
Recomendado: imagen cuadrada (1:1), mínimo 600×600 px, fondo limpio.

Ver la guía completa en /CATALOGO.md
