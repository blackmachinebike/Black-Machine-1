# Logotipo

Coloca aquí el logotipo oficial como `logo.png` (o `logo.svg`) con este nombre exacto:

- `assets/logo.png`

El header lo detecta automáticamente: si el archivo existe, muestra la imagen;
si no, usa el ícono + texto de respaldo. Recomendado: PNG con fondo transparente,
alto ≥ 96 px. Si usas otro formato, actualiza el `src` en `tienda.html`
(`<img id="brandImg" src="assets/logo.png">`).
